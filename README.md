# 🚀 Space Invaders 3D

A 3D interactive web-based game built with Three.js for Software Engineering Project.

## 🎮 Live Demo
https://hli-yt.github.io/space-invaders-3d/

## 📋 Project Requirements Met

### ✅ Technical Requirements
- **5+ Unique 3D Objects**: Player ship, 4 types of invaders, bullets, stars, ground
- **Camera Controls**: OrbitControls for interactive 3D viewing
- **Lighting System**: Ambient + Directional + Point lights with shadows
- **User Interaction**: Keyboard controls (movement/shooting) + Mouse camera control
- **Texture/Materials**: Phong materials with emissive properties and colors
- **Animation**: Moving invaders, flying bullets, particle explosions, floating effects

### ✅ Game Features
- Score tracking system
- Lives system (3 lives)
- Wave progression
- Collision detection
- Visual effects (explosions, lighting)
- Game states (Start, Playing, Game Over, Victory)
